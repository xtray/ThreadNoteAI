# ThreadNote AI 用户操作手册

## 这是什么安装包
这个安装包包含 ThreadNote AI 的 Microsoft Edge 离线扩展版本。

你解压后，无需通过插件商店，也可以在 Edge 中手动安装和使用。

## 在 Edge 中以开发者模式安装
1. 先把 zip 安装包保存到本地电脑。
2. 解压到一个准备长期保留的文件夹。
3. 打开 Microsoft Edge。
4. 在地址栏输入 `edge://extensions`。
5. 在扩展页面开启“开发人员模式”。
6. 点击“加载解压缩的扩展”。
7. 选择刚才解压后的扩展目录。
8. 确认扩展列表里出现 `ThreadNote AI`。
9. 如有需要，可以把扩展固定到 Edge 工具栏，方便以后打开。

请注意：
- 不能直接选择 zip 压缩包，必须选择解压后的文件夹。
- 当 Edge 让你选择目录时，请选择包含 `manifest.json` 的那个目录。
- 安装后不要随意移动或删除这个解压目录，否则 Edge 可能无法继续正常加载扩展。
- 这个安装包主要用于小范围试用，所以安装方式是通过“开发人员模式”加“加载解压缩的扩展”完成的。

## 使用前准备
开始使用前，请确认你已经具备：
- 至少一个可用的 AI 提供商 API Key
- 已开启开发者模式的 Microsoft Edge
- 当前电脑允许浏览器保存本地数据

当前版本支持的提供商包括：
- MiniMax
- Zhipu GLM
- DeepSeek
- OpenAI
- Anthropic
- Google Gemini
- 自定义 OpenAI 兼容提供商

## 首次配置
1. 在 Edge 工具栏打开 ThreadNote AI 扩展。
2. 打开 `Settings`。
3. 填入你要使用的 AI 提供商 API Key。
4. 选择主会话模型。
5. 选择子会话模型。
6. 如果页面提示保存，就完成保存。
7. 新建一个聊天，发送一条简短消息确认模型调用正常。

## 推荐使用流程
为了更顺畅地完成第一次体验，建议按这个顺序操作：
1. 先在 Edge 中完成扩展安装。
2. 打开扩展并配置一个 API Key。
3. 在主会话里发送一条简短测试消息，确认连接正常。
4. 选中一段 AI 回复内容，体验一次子会话。
5. 把一段有价值的内容加入 Notebook。
6. 在配置完成后先导出一次数据，作为初始备份。

这样可以一次性确认扩展安装、模型调用、子会话和笔记能力都正常工作。

## 安装失败排查对照表
| 如果你看到的现象 | 可能原因 | 建议处理 |
|---|---|---|
| 看不到“加载解压缩的扩展”，或者按钮不可用 | “开发人员模式”还没有开启 | 打开 `edge://extensions`，先开启“开发人员模式” |
| Edge 不接受你选择的目录 | 你选到了 zip 文件，或者选错了文件夹层级 | 先完整解压，再选择包含 `manifest.json` 的那个目录 |
| 扩展出现在列表里，但点不开 | 解压目录被移动、删除，或内容覆盖不完整 | 在 Edge 里移除这个解压扩展，再重新加载当前目录 |
| 重新装了新版本，但看起来还是旧版本 | Edge 仍然在用旧的解压目录 | 先移除旧版本，再对新目录执行“加载解压缩的扩展” |
| 扩展能打开，但聊天一开始就失败 | API Key 或模型设置还没配好 | 打开 `Settings`，检查 API Key 和模型，并发送一条短消息测试 |

## 主会话聊天
- 点击 `New Chat` 开始新对话。
- 输入问题并发送。
- 主会话支持最多 3 个模型并发回答。
- 当同一轮出现多个回答时，可以对比后保留你想作为主上下文的结果。
- 回复生成过程中，可以点击 `Stop` 中止。

## 子会话
- 在 AI 回复中选中文本后，可以创建或打开子会话。
- 子会话适合围绕局部内容继续深入追问，不打断主线程。
- `Keep` 表示后续提问会继续使用保存下来的主线程快照，以及子会话自己的历史。
- `New` 表示后续只使用子会话自身历史。
- 你也可以把有价值的子会话内容加入笔记。

## Notebook
- 使用 `Notebook` 标签页管理 Markdown 笔记。
- 编辑器聚焦时显示 Markdown 原文。
- 失焦时显示渲染结果。
- 右键笔记可以删除，或者导出当前笔记为 Markdown。

## 导入与导出
- Notebook 数据支持导出备份，也支持后续导入。
- AI 配置支持在 Settings 中导出和导入。
- AI 聊天记录也支持在 Settings 中导出和导入。
- 在大批量导入或整理数据前，建议先导出一份备份。

## 升级前建议先导出这些数据
安装新版本前，建议先导出下面这 3 项：
- AI 聊天记录
- AI 配置
- Notebook 笔记数据

## 升级到新版本
当你收到新的离线安装包时，建议这样升级：
1. 如果需要稳妥备份，先导出重要数据。
2. 解压新的安装包到一个新目录，或者替换旧目录内容。
3. 打开 `edge://extensions`。
4. 移除旧的 ThreadNote AI 解压扩展，或者在你明确知道自己覆盖的是同一目录时使用重新加载。
5. 点击“加载解压缩的扩展”，重新选择新版本目录。
6. 打开扩展，确认配置和数据看起来正常。

建议：
- 每次升级前先做一次备份导出。
- 不要在 Edge 正在使用扩展时随意删除扩展目录。

## 常见问题
- 如果模型请求立即失败，请先检查 Settings 中的 API Key 和模型选择。
- 如果安装后扩展打不开，请到 `edge://extensions` 中移除后重新加载解压目录。
- 如果升级后出现异常，建议移除旧版本后，再重新安装新的解压目录。
- 如果导入后的数据不符合预期，请用最近一次导出的备份恢复。

## 数据与安全说明
- 聊天记录和笔记保存在当前浏览器配置文件的本地数据中。
- API Key 和模型设置保存在浏览器本地存储中。
- 更换浏览器配置文件或设备后，数据不会自动同步。
- 请妥善保管你的 API Key。
- 离线安装包只建议分发给可信任的使用者。
